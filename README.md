Windows 单音简谱播放器：编辑和保存 TXT、本地声音试听、导出标准 MIDI，以及通过模拟键鼠在游戏内演奏。

## v0.5.0 更新（本地增量，待维护者实机验收后升版打包）

本次新增“曲谱库：每首曲子可以绑一个自己的快捷键”。曲谱库只登记“TXT 文件 + 显示名 + 快捷键”，不改曲谱语法、文件头、BPM、间隔、试听、MIDI 和游戏时间线。

- **曲谱库卡片**：点“添加曲谱…”可一次多选 TXT（上限60首），列表显示曲名、绑定键和状态（快捷键可用／被其他程序占用／未绑定快捷键／文件不存在），当前编辑器里打开的曲谱标“（当前）”。支持上移、下移、移除。
- **移除不动文件**：“移除”只把曲谱从列表去掉，不删除 TXT，也不改变编辑器内容；“上移/下移”只调整列表顺序，顺序决定快捷键编号。
- **每曲一键**：选中一行点“绑定快捷键…”绑定一个全局按键，默认建议未被占用的 F1～F11。与开始键、停止键相同的组合，以及两首曲子用同一个键，会在写入设置前被拒绝并说明原因。快捷键编号从100起，与开始（1）／停止（2）互不干扰；某一首注册失败只影响这一首，其他曲谱继续可用。
- **按下之后**：按曲谱快捷键即加载并演奏（3秒倒计时，倒计时和演奏都可用停止键取消）；取消勾选“按快捷键立即演奏（不勾选则只加载曲谱）”后只把曲谱加载进编辑器。演奏中或正在读写曲谱时按键不生效，状态区提示“正在演奏或读写曲谱，本次曲谱库快捷键未生效。”；当前曲谱有未保存修改时，快捷键切换被取消，并提示先保存或新建。
- **数据安全**：曲谱库设置损坏（手工编辑、跨版本残留）时只清理曲谱库本身——丢弃无效条目、清除冲突快捷键，提示“曲谱库数据有问题，已自动清理（…）”，速度、间隔、开始/停止键等其他设置不受影响。
- 曲谱库、每曲绑定和“立即演奏”开关随软件设置保存；导出的 TXT 与 MIDI 不因曲谱库改变。

## v0.4.0 更新

本次新增“导入单旋律 MIDI”。选择 .mid/.midi 后选择轨道/通道，查看音域、移调建议和覆盖率；移调默认0，需要主动点击应用建议。任何音符重叠都拒绝，不自动取主旋律、删音、改音长或量化。检查通过后导入当前编辑器，作为未保存的 TXT，先试听再保存/演奏。

支持标准 MIDI Format 0/1、PPQ；文件上限16MB、256轨、500000事件。速度变化按原始实际时间转成固定 BPM 的自定义时值。当前 MIDI 映射覆盖48～85全部半音（C3～C#6），包含最高do的升半音。打击乐、弯音、踏板、SysEx及不支持的格式会明确提示，不能保证原乐器演奏效果。

按维护者确认的游戏状态，中音、低音、高音的1～7均可升半音，包含#3和#7。双层音区仅支持`【【1】】`与新增的`【【#1】】`，**不支持双层2～7，包括升半音**。新增兼容全角`＃`，如`【【＃1】】`；新制谱推荐半角`#`。半音与高/低音区修饰键可同时保持；最高do升半音用右键＋中键＋逗号。

导入参数默认 gap=10ms，用户可以修改；不从 MIDI 推断 gap。程序按“原发声时长＋目标gap”生成音符，再补足显式休止，保留起音、Note Off 和所选轨道总时长。原间隙不足gap、发声不足52ms、末尾没有足够留白或超出谱面限制时阻止导入并显示具体音符/时间；普通连奏 MIDI 因此可能需要先在原 MIDI 编辑器处理，本版不自动调整。

每次启动默认不勾选“仅测试（不会操作游戏）”，显示“开始演奏”；勾选后为“开始测试”，不操作游戏也不发声。主界面显示进程权限和模式。未管理员运行只提醒可能存在权限不匹配，允许继续；试听、测试、MIDI 不要求管理员。保留3秒倒计时、停止热键检查和演奏中的失焦保护。

短休止使用独立50ms调度容差；发声音符仍使用原严重迟到保护。超时后释放输入，并报告行列、片段、音/休止序号、曲内时间、实际迟到和阈值，可定位到谱面；错误对话框在清理结束后显示。不会自动合并休止或改动原谱。

暂停和播放列表暂缓；管理员重启和“确认后调整 MIDI”留待后续评估。本版不自动调整源MIDI或改变原谱的BPM、gap和时值。

## 本地试听与 MIDI

导入 TXT 后点击“从头试听”；需要核对局部时，把光标放到正文的音符上，点击“从光标试听”。光标在空白、小节线或音符前的括号/#上时从下一音开始；在时值符号或结束括号上时从所属音开始；正文末尾从最后一音开始。会试听到曲末，不循环。停止按钮或已注册的停止快捷键均可停止；快捷键冲突不妨碍按钮试听和停止。

中音1=C4（MIDI 60）、低音1=C3、高音1=C5、最高do=C6；v0.4.0补充最高do升半音=C#6（MIDI 85）。#升半音，v0.4.0也兼容全角＃。原谱调号不会自动移调。试听采用真实口琴录音，但不保证与游戏音色或绝对音高一致。

每音按谱面拍数占用时间，末尾扣除当前 gap 作为留白，不在总时长之外加间隔。休止按完整时值静音。游戏输入需要的12ms按键准备不作为试听/MIDI的前置静音；三种方式的拍点和总时长一致，游戏按住时间额外少12ms。为保持游戏可演奏性，所有入口仍执行原12ms准备＋40ms按住的校验。

“导出 MIDI”始终导出当前编辑中的整首曲谱，不受光标位置影响；不用先保存 TXT，也不会清除标题星号。使用标准 MIDI Format 0、单轨、9600 PPQ、一个固定速度、GM口琴音色（22号，程序号21）、固定力度96。MIDI不含采样音频，外部播放器音色可能不同；试听音量不影响导出。导出先写临时文件再替换，失败保留已有目标。未定义拍号，不向MIDI猜填拍号。外部软件可能把未标拍号的文件显示为默认4/4，这不改变音符时值。

v0.4.0支持上述单旋律MIDI导入；暂不包含暂停、播放列表、动态BPM播放器或和弦。TXT继续使用 HarmonicaPlayer/1，无需转换旧谱。

## 使用

解压发布包，运行 HarpKit.exe，导入TXT或单旋律MIDI并确认速度（BPM）和间隔。每次启动默认不勾选“仅测试（不会操作游戏）”；点击“开始演奏”或按默认F6前，进入游戏口琴界面，默认F8停止。需要检查流程时主动勾选仅测试，此时按钮为“开始测试”，不发声、不发送键鼠。

停止键冲突时禁止实际演奏；开始键冲突时仍可点开始按钮，在3秒倒计时内切入游戏。权限应与游戏匹配，需要时以管理员运行；游戏建议无边框模式。演奏时除停止键外不要操作键鼠。

曲谱库：点“添加曲谱…”把常弹的 TXT 加进列表（可多选），选中一行点“绑定快捷键…”设置按键，例如未被占用的 F1。之后无论在哪个窗口，按这个键都会加载并演奏这首曲子（3秒倒计时，停止键随时取消）；只想加载不想自动演奏，就取消“按快捷键立即演奏（不勾选则只加载曲谱）”。快捷键与开始/停止键共用同一套注册，冲突时会明确提示；演奏中按键不生效，会提示请先停止。

## TXT格式

旧纯音符TXT仍可导入。文件名可写“歌名 bpm100.txt”“歌名_BPM100.txt”“歌名-bpm100.txt”“歌名 bpm 100.txt”。BPM为20～300整数。

建议在软件内保存新格式：

```text
@format=HarmonicaPlayer/1
@title=节奏示例
@bpm=120
@gap=20

1 2_ 3_ 5 — |
0 6. 5_ 1 |
```

- 文件格式版本与软件版本独立。新格式要求@format和@bpm；@title可省略，导入时用文件名。界面曲名不能为空。
- 文件头与正文之间必须有空行。同名字段不能重复（不区分大小写）。未知字段提示后原样保留，但不解释其作用，例如@time不会改变节拍。
- 文件头与文件名BPM冲突时以文件头为准并提示。没有BPM时沿用界面有效速度，界面无效则使用最后有效设置。
- @gap可省略，省略时使用20ms（旧纯音符TXT也一样）。填写时必须是10～5000的整数；空值、越界、重复字段会报错。保存时自动写入当前间隔。间隔不会改变每拍总时长，但会缩短按住时间，仍受最短音校验限制。
- UTF-8，最大1MB。文件头不要粘贴进音符编辑区。
- 保存前检查曲谱、速度和间隔；先写同目录临时文件再替换目标。验证或写入失败不覆盖已有目标。
- v0.2.0及更早版本不识别新文件头；旧版兼容请单独复制正文到TXT，并在旧版设置BPM。

## 音符规则

| 写法 | 含义 |
|---|---|
| 1～7 | 中音，一拍 |
| 【1】～【7】 | 高一个八度 |
| （1）或(1) | 低一个八度 |
| 【【1】】、【【#1】】 | 双层仅最高do及其升半音，后者为v0.4.0新增 |
| #1、（#3）、【#7】 | 中/低/高音区1～7均支持升半音；v0.4.0兼容全角＃ |
| 0 | 休止一拍 |
| 5_、5__ | 半拍、四分之一拍 |
| 5.、5_. | 1.5拍、0.75拍 |
| 5 —、0 — | 增加一拍 |
| 5:1.25 | 同一个音总共持续1.25拍 |

推荐用空格分隔音符；旧谱连写 `565`、分组音区 `【123】`、普通音区括号内时值 `【3_.】` 仍兼容。冒号指定总拍数，大于0且不超过64，不可再混用下划线、附点或延长符。双层音区不支持2～7（含升半音），只接受【【1】】、【【#1】】；时值写在括号外，如【【#1】】:1.25。【【#1】】和全角＃需v0.4.0及以后版本，已发布v0.3.3不支持。空格、换行、小节线不增加停顿；小节线不执行满拍检查。扣除12ms准备和间隔后至少按住40ms，否则降低BPM或减小间隔。

完整写法见“制谱说明.txt”，AI提示词见“ai转谱模板.txt”，操作问题见“使用说明.txt”。

```powershell
dotnet run --project .\Tests\ParserTests.csproj -c Release

powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Release.ps1
```

脚本在检查失败时停止，生成bin\Release\HarpKit-v0.4.0-win-x64.zip（含 HarpKit.exe 自包含程序、说明、模板和内置示例）。本次发行包不包含“简谱”文件夹；默认打包行为也是如此，仅明确传入-IncludeScores时才附带本机TXT曲谱。

测试项目是自定义控制台检查，不能用 `dotnet test` 替代。核心入口可后台运行；WindowsSmoke 会创建窗口并注册全局热键，必须避开游戏期间。它使用日志播放和音频替身，不验证真实音频或游戏输入。修改游戏调度、快捷键或取消逻辑后，需要重新验收对应的实机行为，不能沿用旧版结果。

后台构建与定向检查（不启动播放器、不占用热键）：

```powershell
dotnet build .\HarpKit.csproj -c Release
dotnet build .\Tests\WindowsSmoke\WindowsSmokeTests.csproj -c Release
dotnet run --project .\Tests\ParserTests.csproj -c Release -- --playback-timing-only
```

游戏循环使用 GamePlaybackTiming 的时间计划；试听和 MIDI 使用 ScoreTimeline，自动检查对照两者拍点、总时长、休止、gap 和游戏独有的 12ms 准备。重复开始、停止再开始的窗口回归在 WindowsSmoke 中；编译通过不代表窗口回归已执行。

