# 2026-10-03 音区与升半音验证

本记录续接 [WindowsSmoke 反馈与复验](VALIDATION-2026-10-03.md)。维护者确认六种游戏界面状态，并明确“不支持双层 2～7”。本次先改代码、运行后台检查及构建，再同步说明文件。正式发布基线仍为 v0.3.3；当前成果属于未发布开发工作区。

## 确认的语法与输入映射

- 中音、低音、高音的 1～7 都可升半音，包含 `#3`、`#7`。等音关系不限制这些输入写法。
- 双层音区仅支持 `【【1】】` 与 `【【#1】】`。**不支持双层 2～7，包括其升半音**；解析错误指向实际数字位置。原生输入计划也拒绝非法的双层音模型。
- `＃` 与 `#` 等价，包含 `【【＃1】】`。保留原 TXT 拼写、源字符位置和错误行列；MIDI 转 TXT 使用半角 `#`。
- 双层音区时值只能写在括号外，如 `【【#1】】:1.25`；不接受 `【【#1_】】`。
- 试听、MIDI 导入/导出固定音高范围为 **C3～C#6，MIDI 48～85，共 38 个半音**。MIDI 86 及以上仍拒绝导入，整体移调建议仍需用户主动确认。
- BPM、gap、音符时值、12ms 准备和输入释放规则没有因音域补全而修改；采样资源未更换。

以下依据维护者提供的六张游戏界面截图及确认。表中鼠标修饰键与音符主键同时保持，实际游戏响应尚待维护者验证。

| 状态 | Z / X / C / V / B / N / M | 逗号键 |
|---|---|---|
| 默认 | `1`～`7` | `【1】` |

| 右键：升调 | `【1】`～`【7】` | `【【1】】` |

| 右键＋中键 | `【#1】`～`【#7】` | `【【#1】】` |

程序沿用已有等效主键选择：`【1】` 用逗号，`【#1】` 用中键＋逗号；`【【#1】】` 用右键＋中键＋逗号。没有增加双层 2～7 的输入映射。

## 代码及回归覆盖

`ScoreParser` 处理全角升号、双层最高升半音及明确的双层 2～7 拒绝。`HarmonicaPitchMap` 将上界扩展为 85，供试听和 MIDI 共用；`MidiImporter` 的范围提示使用该常量。`ScoreTimeline` 的光标定位兼容全角升号。

新增纯计算的 `GameNoteInput`，由 `NativeInput.Modifiers/NoteOn` 与无设备测试共用。低/高音区和升半音分别决定鼠标键，不互相排斥；实际发送、记录尝试按下的键以及释放顺序保留原实现。核心测试没有链接 `NativeInput`，不会调用 SendInput。

新增 `Tests/PitchInputTests.cs`，覆盖三种普通音区的 1～7 及升半音、主键扫描码与鼠标修饰组合、两个最高音、全角/半角混用、非法嵌套、精确源位置、TXT 保存往返，以及双层 2～7 的解析和输入计划拒绝。已有 MIDI、音频模型、游戏/共享时间线检查增加最高升半音边界。
